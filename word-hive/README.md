# 🐝 Word Hive

A honeycomb word puzzle. Make as many words as you can from 7 letters, and every word must use the gold centre letter.

## Run it

It needs no build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server -d word-hive 8000
# then visit http://localhost:8000
```

## How to play

- Type, or tap the hexagons, then press **Enter**. **Backspace** deletes and **Space** shuffles the outer letters.
- Words need 4+ letters and must include the centre letter. Letters can be reused.
- A 4-letter word scores 1 point, and longer words score 1 point per letter. A **pangram** (a word using all 7 letters) earns +7.
- Ranks go from Beginner 🥚 to Queen Bee 👑 as you collect points.
- **Today** gives everyone the same puzzle for the date. **New puzzle** picks a random one from 3,000+.
- Progress for each puzzle is saved in your browser.

## Word list

`words.js` is generated by `tools/build_words.py` from [SCOWL](http://wordlist.aspell.net/) (via the `wordlist-english` npm package). It uses only the common-word tiers, drops words containing **S** (so plurals don't make it too easy), and filters out words that aren't family-friendly. See `WORDLIST-COPYRIGHT.txt` for the word list licence.

To regenerate it:

```bash
cd /tmp && npm pack wordlist-english && tar xzf wordlist-english-*.tgz
python3 word-hive/tools/build_words.py /tmp/package
```

To tune it, change `ACCEPT_TIERS`, `BLOCK_PREFIXES` or the answer-count range at the top of the script.
